# NEXO Mobile — initial prototype

Created for the Edward Tejada app project. This is an early, non-functional UI scaffold built with Expo and React Native.

## Current state
- Dark, mobile-first home screen
- Provisional NEXO identity
- Edward Tejada creator signature
- Placeholder cards for AI, daily planning, goals, and finances
- No backend, accounts, persistence, analytics, or AI requests yet

## Security notes
This prototype intentionally stores and transmits no user data. Security architecture, authentication, encrypted storage, backend authorization, privacy review, threat modeling, and dependency review must be completed before sensitive features are introduced.

## Run locally
Install Node.js LTS, then:

```sh
cd mobile
npm install
npx expo start
```

Use Expo Go to scan the development QR code, or run the Android/iOS command on a supported development environment.
